# Rider scripts

`scripts.jsonl`, one row per utterance. Gold `action` and `safety` are filled by `src/labels.py:label_row`, never by hand.

```json
{"id": "cu_hing_007", "situation": "customer_unreachable", "language": "hinglish", "stage": "drop",
 "cues": {"attempts": 3, "waited_min": 12}, "register": "irritated", "kind": "typical",
 "text": "bhai teen baar call kiya, customer utha hi nahi raha, 12 minute ho gaye gate pe",
 "text_tts": "भाई तीन बार कॉल किया, कस्टमर उठा ही नहीं रहा, बारह मिनट हो गए गेट पे"}
```

| Field | Values |
|---|---|
| `situation`, `language` | ids from `spec/decision_set.json` |
| `stage` | `pickup` · `en_route` · `drop` |
| `cues` | any keys used by `action_rules` / `safety_rules` (`attempts`, `waited_min`, `near_restaurant`, `minor`, `rider_ok`, `medical_emergency`, …) |
| `register` | `calm` · `irritated` · `panicked` · `tired` |
| `kind` | `typical` · `contrast` (hard negatives, look-alikes) · `terse` |
| `text` | what the rider says, romanised for Hinglish/Hindi |
| `text_tts` | the same in native script with numbers spelled out, for TTS |

Rules for every row: 2–25 words (terse fragments are short on purpose); no real names, addresses or phone numbers; no delivery-platform names.

## Files

- `m1_wedge.raw.jsonl` — 130 scripts for the door-step wedge (customer unreachable, wrong address, payment, dispute,
  threats at the door, other). Drafted, then **reviewed by a native speaker before use**. Cues are written so they are
  audible in the words ("teen baar call kiya" → `attempts: 3`).
- `m1_wedge.jsonl` — the built file (labels + splits), regenerated by `src/scripts.py build`.
- `m1_round2.raw.jsonl` — 86 round-2 scripts: implicit threats (followed, cornered, crowd, keys grabbed), injuries,
  customer-unreachable contrast triples (one sentence, only the call-count / wait cue changes) and payment-vs-dispute
  pairs. Built together with round 1 using `--freeze-splits data/scripts/m1_wedge.jsonl`.
- `m1_v2.jsonl` — the built round-2 file (216 scripts).
- Optional fields: `ambiguous` (a native speaker could reasonably choose another label; kept and reported
  separately, with `ambiguity_note`), `group` (contrastive siblings; always land in the same split).
- The rest of the 480 come from `src/scripts.py grid` → `draft` → review → `build`.

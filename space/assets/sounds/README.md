# Alert sounds (optional)

The app looks here for licensed clips:

- `checkin.wav` — a short, soft chime for an "Are you safe?" check-in
- `sos.wav` — a distinct alarm for an SOS alert

Neither file is shipped in this repo. If they are missing, the mute toggle still works and the hook stays silent — no synthesized beeps are generated. Drop licensed files in this folder before a recorded demo if you want audio cues. A mute control is on the console either way.
